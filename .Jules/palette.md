## 2026-06-16 - Tap-to-Copy for Financial Details
**Learning:** In Telegram bots, wrapping numeric data like account numbers, phone numbers, and transaction IDs in monospace backticks (Markdown) enables 'tap-to-copy' functionality. This reduces friction in payment and verification workflows where users must transfer data between apps.
**Action:** Consistently use monospace formatting for any data the user might need to copy and paste.
