## 2026-06-16 - Tap-to-Copy for Financial Details
**Learning:** In Telegram bots, using monospace formatting (backticks) for critical information like account numbers, transaction IDs, and amounts significantly improves UX by enabling "tap-to-copy". This reduces user friction and errors during manual payment processes.
**Action:** Always wrap sensitive or actionable data (IDs, phone numbers, amounts) in monospace blocks and use bold headers to maintain clear visual hierarchy.
