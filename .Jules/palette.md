## 2026-06-16 - Tap-to-Copy Monospace Blocks
**Learning:** In Telegram bot interfaces, users often need to copy sensitive or specific data like account numbers, phone numbers, or transaction amounts to use in other apps (e.g., banking apps). Using monospace formatting (backticks) enables 'tap-to-copy' functionality in many Telegram clients, significantly reducing friction.
**Action:** Always wrap critical data like financial details, account numbers, and phone numbers in monospace backticks to improve user efficiency and reduce manual entry errors.
