# Palette's Journal

## 2026-07-16 - Tap-to-Copy Phone Formatting vs Clickable Telegram Handles
**Learning:** Monospace code blocks (`...`) in Telegram Markdown enable single-tap copying on mobile clients, which is optimal for phone numbers. However, wrapping Telegram handles (e.g., `@mezzodeposite`) in backticks prevents clients from rendering them as clickable links to open a direct chat.
**Action:** Always format phone numbers in monospace backticks for quick copying while leaving `@mentions` unformatted to preserve clickable chat linking in support messages.
