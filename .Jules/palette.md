## 2026-06-16 - Tap-to-Copy for Financial Data
**Learning:** Users in financial bot contexts highly value the ability to quickly copy account numbers, transaction IDs, and balances. Using monospace formatting (`code`) in Telegram triggers 'tap-to-copy' on mobile clients, significantly improving the UX for deposits and withdrawals.
**Action:** Always wrap account numbers, phone numbers for payment, and balances in monospace backticks when using Markdown in Telegram bots.
