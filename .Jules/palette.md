## 2026-07-16 - Support Menu Micro-UX Polish
**Learning:** Monospace formatting in Telegram Markdown allows user tap-to-copy functionality for critical contact information like phone numbers, while maintaining clickable handles (e.g. `@mezzodeposite`) requires leaving them unformatted. Bold headers enhance vertical visual hierarchy.
**Action:** Use `*HEADER*` for section headers, wrap numbers in backticks, keep handles unformatted, and explicitly specify `parse_mode="Markdown"`.
