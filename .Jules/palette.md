# Palette's Journal - Mezzo Bot

## 2026-06-16 - Tap-to-Copy for Financial Details
**Learning:** In Telegram bots, wrapping text in monospace backticks (`` `text` ``) enables a "tap-to-copy" feature on mobile clients, which significantly improves UX for account numbers and IDs.
**Action:** Always use monospace formatting for account numbers, phone numbers, and user IDs that might need to be copied.
