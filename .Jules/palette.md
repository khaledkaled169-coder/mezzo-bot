## 2026-07-16 - Monospace tap-to-copy for payment instructions
**Learning:** Telegram users transferring money via CBE or Telebirr often manually transcribe account/phone numbers unless formatted in monospace backticks (`code`), which allows instant tap-to-copy in Telegram mobile/desktop clients.
**Action:** Always format account numbers, phone numbers, and financial details using monospace code blocks in Telegram bot payment instruction messages.
